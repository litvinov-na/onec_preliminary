# Отбор на бакалавриат КИС 2026

* Автор: Литвинов Никита Алексеевич

* Выбранная задача: #2 Клиентские приложение 16 октября

Приложение позволяет создавать, удалять, редактировать блюда (dishes) и приемы пищи (meals).
А также просматривать на графике количество ккал в каждом приеме пищи и в целом за день.

## How to build

* Install [Flutter](https://docs.flutter.dev/get-started/install)

* Clone this repository

* Run `flutter run`
